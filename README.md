# Employee Performance Dashboard

## Project Overview

This is a Business Analyst portfolio project created using Microsoft Excel to analyze employee data and present meaningful business insights through an interactive dashboard.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- KPIs
- Data Visualization

## Key KPIs

- Total Employees
- Average Salary
- Average Bonus %

## Dashboard Analysis

The dashboard analyzes:

- Employee Performance Rating
- Employee Satisfaction
- Average Salary by Department
- Employee Distribution by Region

## Interactive Features

The dashboard includes slicers for:

- Employment Type
- Department
- Region
- Performance Rating

These slicers allow users to interactively filter the dashboard and analyze employee information based on different categories.

## Objective

The objective of this project is to transform raw employee data into an interactive Excel dashboard that helps understand employee performance, satisfaction, compensation, and workforce distribution.

## Key Learning

Through this project, I practiced data cleaning, PivotTables, PivotCharts, KPI creation, slicer connections, data visualization, dashboard design, and business-oriented data analysis.
